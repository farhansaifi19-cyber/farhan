Schwing Stetter Mohali Service Call App — Version 2

Open index.html in a mobile browser. For an app-like shortcut, use the browser menu and choose Add to Home Screen if available.

Features:
- Manually enter customer and service-call information.
- Dropdowns:
  Work Type: Breakdown, Service, Installation, Inspection
  Call type: Warranty, Non warranty, AMC, Good will visit
  Status: Pending, In Progress, Completed
- Save Entry and + New Entry.
- Saved entries can be edited or deleted.
- Add, rename, and delete columns.
- Local browser storage; export Excel or CSV for backup.
- Import Excel reads the first worksheet and replaces the current app table after confirmation.

Important:
- This is a mobile web app prototype, not a compiled Android APK.
- Data stays in the same browser/device unless exported. Clear browser data only after exporting a backup.
- Excel import/export uses a spreadsheet library loaded from a CDN and therefore needs internet access for that operation.
- Export creates a new workbook from the app's current table; it does not preserve every feature/formatting of the original workbook.
